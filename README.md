# 🔎 AI Essay Detector for College Admissions

An explainable statistical NLP web application designed to analyze college admission essays, identify machine-generated writing patterns at the sentence and passage level, and provide transparent visual evidence rather than relying on a single opaque AI score.

## 🎥 Demo / Walkthrough

> **Technical Walkthrough:** [https://loom.com/share/e95993d7574d428ca04a8a7f1335b8b8](https://loom.com/share/e95993d7574d428ca04a8a7f1335b8b8)

## ✨ Features

* **Sentence-Level Analysis:** Breaks an essay into individual sentences and clauses and analyzes each segment independently.
* **Visual Highlighting:** Color-codes suspicious sections based on calculated AI-generation probability.
* **Explainable Evidence:** Shows the linguistic and statistical signals behind flagged text, including perplexity, burstiness, repetition, and structural patterns.
* **Statistical NLP:** Uses token distributions, sentence rhythm, entropy, and related statistical features rather than relying on third-party prompt-wrapping services.
* **Interactive Web Interface:** Provides a fast, responsive interface for real-time essay analysis.
* **Transparent Evaluation:** Includes benchmark results and documented failure cases instead of presenting the detector as perfectly accurate.

## 📊 How Detection Works

The detector does not treat one characteristic as proof that an essay was generated by AI.

Instead, it analyzes multiple statistical properties of the submitted text, including:

1. **Token distribution**
2. **Sentence structure**
3. **Perplexity-related patterns**
4. **Burstiness / variation in sentence patterns**
5. **Repetition and structural regularity**
6. **Textual entropy**

These signals are combined to produce an estimated AI-likelihood score and provide evidence at the sentence/passage level.

> **Important:** AI detection is probabilistic. A score should be interpreted as an analytical signal, not definitive proof that a particular person used AI.

## 📁 Dataset & Evaluation

The detector was evaluated against a benchmark dataset of **60 college-admission-style essays**, consisting of:

* **30 human-written essays** sourced from publicly available college-admission repositories, personal statements, and academic writing sets.
* **30 AI-generated essays** generated using multiple large language models, including models such as GPT-4, Claude, and other contemporary systems.

The dataset was designed to include both straightforward examples and difficult edge cases.

## 📈 Benchmark Results

The current benchmark produced approximately:

| Metric                   |     Result |
| ------------------------ | ---------: |
| Overall Test Accuracy    | **~83.3%** |
| Precision on Raw AI Text |   **~91%** |
| False Positive Rate      |   **~13%** |

The false-positive cases occurred primarily on highly structured academic writing and non-native English writing.

These results should be interpreted as a benchmark for this specific dataset rather than as a universal measure of AI-detection accuracy.

## ❌ Failure Case Analysis

A major goal of this project is to document where statistical AI detection can fail.

### 1. False Positive — Non-Native / ESL Human Personal Statement

**Scenario:**
A personal narrative written entirely by an ESL applicant was flagged with a high AI-likelihood score.

**Root Cause:**
ESL writers may naturally use relatively consistent transition patterns such as *“Furthermore,” “In addition,”* and *“Consequently.”* Their writing can also have relatively consistent sentence structures and vocabulary distributions.

These characteristics can resemble patterns commonly associated with machine-generated text, even when the writing is completely human.

---

### 2. False Positive — Highly Formulaic Academic Essay

**Scenario:**
A human student's analytical essay about a historical milestone was flagged with approximately **74% AI probability**.

**Root Cause:**
Formal academic writing naturally tends to use:

* Uniform sentence structures
* Passive voice
* Conventional academic vocabulary
* Predictable transitions
* Consistent sentence rhythms

When these characteristics occur together, the statistical structure of genuine human writing can resemble machine-generated prose.

---

### 3. False Negative — Prompt-Engineered / "Humanized" AI Essay

**Scenario:**
An AI-generated essay deliberately written with irregular sentence cadence, varied sentence lengths, rhetorical questions, and occasional informal expressions was classified as human-written, receiving approximately **18% AI probability**.

**Root Cause:**
Deliberately introducing burstiness, mixing short fragments with longer sentences, and varying punctuation can increase measured entropy and disrupt the statistical patterns normally used by the detector.

This demonstrates that a sufficiently humanized AI-generated essay can evade a detector based primarily on statistical surface-level features.

## 🎯 Design Philosophy

This project is intentionally built around **explainability rather than a single black-box percentage**.

Instead of simply saying:

> "This essay is 82% AI."

the application attempts to answer:

> **"What characteristics of this text caused the detector to reach that conclusion?"**

This makes the system more useful for experimentation, research, and educational analysis while also making its limitations visible.

---

## ⚠️ Limitations

AI-generated-text detection is an inherently difficult problem.

This system should **not** be used as definitive evidence of academic misconduct or to make high-stakes admissions decisions.

Potential sources of error include:

* Non-native English writing
* Highly formal academic writing
* Formulaic personal statements
* Extensive editing or proofreading
* AI-generated text that has been deliberately humanized
* Newer language models with different writing distributions
* Short or insufficient text samples

The benchmark results therefore represent the performance of this implementation on the tested dataset and should not be interpreted as universal detection accuracy.

## 🚀 Getting Started

### Prerequisites

* Python **3.10+**
* `pip`

Clone the repository:

```bash
git clone https://github.com/sunejavishakha10/ai-essay-detector.git
```

Install dependencies:


## 📌 Conclusion

The AI Essay Detector demonstrates how statistical NLP techniques can be used to analyze potential machine-generated writing while keeping the reasoning behind the result visible.

The project also highlights an important limitation of AI detection: **human writing can look like AI, and AI writing can be made to look human.**

For that reason, the system is designed as an **analytical and educational tool**, not as an infallible judge of authorship.
